## [1.0.0] — 2026-05-14

Первый публичный релиз.

### Добавлено

**Методология**
- Аудит по 10 эвристикам Якоба Нильсена с гипотезами о поведении пользователя
- 4-уровневая шкала критичности (🔴 Высокая → 🟢 Нулевая)
- 5 типов влияния (⛔ Ошибки / 💰 Деньги / 🤔 Непонятно / 🐢 Долго / ✨ Всё хорошо)
- Подсчёт общей оценки в % по формуле с весами критичности
- **Консистентный подсчёт оценок** между одиночным аудитом и сравнением: один и тот же концепт получает одинаковую оценку в обоих режимах. В JSON для сравнения используется поле `criticalities` — массив критичностей по концептам.
- **Валидация согласованности** между текстом-выводом (`top_conclusion`) и автоподсчитанными оценками. Скрипт `build_compare.py` сравнивает проценты в тексте с реальными оценками концептов и выдаёт предупреждение в stderr, если числа разошлись (защита от устаревшего текста после правок).

**Режимы вывода**
- Markdown в чате — дефолт для одного экрана и быстрых проверок
- HTML-артефакт — для серий экранов, сравнений и презентаций
- NDA-режим — HTML без встроенных скриншотов

**Режим сравнения концептов**
- Нумерация «Концепт 1, 2, N» (не A/B, не «старый/новый»)
- Параллельный и итеративный режимы
- Лаконичные метки `✓ Концепт N` / `⚖ Паритет`
- Градация преимущества по цвету (насыщенный для 🔴/🟠, бледный для 🟡)
- Карточки сильных сторон с оценкой `N%` справа
- Гибридная рекомендация

**HTML-артефакт**
- Плашка-итог наверху (оценка + главный риск + что исправить)
- Кнопки «Скачать PDF» и «Скачать JPEG»
- Многостраничный A3 PDF через html2canvas + jsPDF
- Белая рамка 24 px при экспорте
- Развёртывание таблицы без обрезки правого края
- Колонки «Проблема» и «Что сделать» одинаковой ширины (440 px) — консистентно в обоих режимах
- Обход sandbox-ограничений Claude.ai через blob-скачивание

**Поддерживаемые входные данные**
- Скриншоты (PNG, JPEG)
- Ссылки на Figma
- Текстовое описание

### Методологическое соответствие

- **Nielsen Norman Group** — для каждой из 10 эвристик приведено официальное определение NN/g со ссылкой на оригинальную статью.
- **Markswebb «Гайд по UX-проблемам»** — формулировка проблем как состояние пользователя (а не свойство интерфейса) с примерами «правильно/неправильно». Шкала критичности (Высокая / Средняя / Низкая / Нулевая) полностью соответствует методологии Markswebb. Дополнительно добавлена расширенная классификация из 12 категорий способов воздействия как опциональная глубина для углублённого разбора.

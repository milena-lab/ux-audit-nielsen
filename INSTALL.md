# Установка скилла

Инструкция по установке `ux-audit-nielsen.skill` в Claude. Несколько способов — выбирайте подходящий.

## Что такое `.skill` файл

`.skill` — это zip-архив со специальной структурой, содержащий:
- `SKILL.md` — описание методологии и триггеров активации
- `references/` — справочники, шаблоны и скрипты сборки

Claude использует этот пакет как контекст: когда вы пишете «проведи UX-аудит этого экрана», Claude находит соответствующий скилл и применяет описанную в нём методологию.

---

## Способ 1. Установка через Claude.ai (рекомендуется)

Подходит для индивидуального использования через веб- или десктоп-приложение Claude.

### Шаги

1. **Скачайте файл `ux-audit-nielsen.skill`** из раздела [Releases](../../releases) этого репозитория (или возьмите из внутреннего корпоративного облака, если ваша компания его распространяет централизованно).

2. **Откройте Claude.ai** в браузере или в десктоп-приложении и войдите в аккаунт.

3. **Перейдите в настройки Skills:**
   - Кликните на свой аватар в левом нижнем углу
   - Выберите **Settings** (Настройки)
   - В меню слева найдите раздел **Capabilities** → **Skills**
   - (точный путь может меняться — если не нашли, ищите по слову «Skills» в поиске настроек)

4. **Загрузите скилл:**
   - Нажмите **Install skill** (или **Upload skill**)
   - Выберите скачанный файл `ux-audit-nielsen.skill`
   - Дождитесь подтверждения — обычно появляется зелёная отметка «Installed»

5. **Готово.** Скилл начнёт работать автоматически в новых чатах при подходящих запросах.

### Требования

Функция Skills доступна в Claude.ai на тарифах Pro, Team и Enterprise. Если в настройках нет раздела Skills — проверьте свой тариф или [актуальную документацию Anthropic](https://docs.claude.com).

---

## Способ 2. Использование через Claude Code (CLI)

Если вы работаете с Claude через [Claude Code](https://docs.claude.com/claude-code), скилл можно подключить локально:

1. Распакуйте `.skill` файл (это обычный zip):
   ```bash
   unzip ux-audit-nielsen.skill -d ~/.claude/skills/
   ```

2. Убедитесь, что путь к скиллу прописан в конфигурации Claude Code (`~/.claude/config.json` или через переменные среды).

3. Перезапустите Claude Code — скилл подхватится автоматически.

---

## Способ 3. Использование без Claude (как утилита)

Если вам нужно только генерировать HTML-отчёты из готовых данных (например, для CI-пайплайна или массовой обработки), вы можете использовать скрипты сборки напрямую, без Claude:

```bash
# Клонируйте репозиторий
git clone https://github.com/milena-lab/ux-audit-nielsen.git
cd ux-audit-nielsen

# Установите зависимости (только Pillow для обработки скринов)
pip install Pillow

# Сгенерируйте артефакт из JSON
python3 references/build_audit.py \
  --data examples/audit-data.example.json \
  --template references/html-template.html \
  --output ./my-audit.html
```

Подробнее — в [examples/README.md](./examples/README.md).

## Распространение внутри команды

Если ваша компания хочет распространить скилл централизованно (через внутренний портал, MDM, Confluence, Notion, корпоративный Google Drive и т.д.):

1. **Положите файл `ux-audit-nielsen.skill`** в общедоступное хранилище компании.
2. **Дайте сотрудникам ссылку** на скачивание и краткую инструкцию (можно сослаться на этот же `INSTALL.md`).
3. **Версионирование:** при выпуске обновлений выкладывайте новые версии с номерами (`ux-audit-nielsen-v1.0.skill`, `v1.1.skill` и т.д.). Сотрудники сами решают, когда обновляться.

> **Безопасность.** `.skill` — это просто zip-архив с текстовыми файлами и Python-скриптами. Перед распространением вы можете распаковать его и проверить содержимое — никакого скрытого кода или внешних обращений в нём нет.

## Как проверить, что скилл установлен

Откройте новый чат в Claude и напишите:

> Проведи UX-аудит этого экрана

Прикрепите любой скриншот интерфейса. Если скилл активен, Claude:
- Применит структурированный разбор по 10 эвристикам Нильсена
- Использует терминологию из методологии (критичность, тип влияния)
- Сошлётся на скилл во вступительной фразе («Использую UX-аудит по эвристикам Нильсена…»)

Если ничего не происходит — проверьте, что скилл включён в настройках (некоторые интерфейсы Claude позволяют временно отключать установленные скиллы).

## Обновление и удаление

### Обновление

Skills в Claude.ai обычно не обновляются автоматически. Чтобы получить новую версию:

1. Удалите старую версию (см. ниже)
2. Скачайте свежий `.skill` из репозитория
3. Установите заново по инструкции из Способа 1

### Удаление

1. **Settings → Capabilities → Skills**
2. Найдите `ux-audit-nielsen` в списке
3. Нажмите кнопку **Remove** (или иконку корзины)
4. Подтвердите удаление

## Решение типичных проблем

### В настройках Claude нет пункта «Skills»

Возможные причины:
- Ваш тариф не поддерживает Skills (проверьте: Pro / Team / Enterprise)
- Функция временно недоступна в вашем регионе
- Вы вошли через корпоративный SSO с ограниченными разрешениями — обратитесь к администратору

### Скилл установлен, но не активируется

- Попробуйте более явные триггер-фразы из README: «Проведи UX-аудит», «Сравни концепты», «Оцени по эвристикам Нильсена»
- Проверьте, что скилл не отключён вручную в настройках
- В новом чате (не в продолжении старого) скиллы активируются чаще — попробуйте начать с нуля

### Кнопки «Скачать PDF» и «Скачать JPEG» в HTML-артефакте не работают

- В Claude.ai preview часть функций может быть ограничена sandbox-окружением
- **Решение:** скачайте сам HTML-файл из артефакта (кнопка скачивания вверху) и откройте его локально в браузере — там кнопки работают полноценно

### Скачанный PDF / JPEG обрезается или выглядит странно

- Это известное поведение, исправлено в актуальной версии скилла
- Убедитесь, что у вас последняя версия — посмотрите [CHANGELOG.md](./CHANGELOG.md)

### Не работает на мобильном

Skills в мобильном приложении Claude поддерживаются, но HTML-артефакты могут рендериться по-другому из-за узкого экрана. Для полноценной работы рекомендуется десктоп или планшет.
